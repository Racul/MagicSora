<<과제 시각화 프로그램 :: 4기 박정민>>

AssignmentList.exe를 실행해서 프로그램 작동 가능

data/assignment.csv 를 직접 조작하여 과제 데이터 입력 가능
id : 과제 고유 번호. 겹치지 않도록 주의
name : 과제 이름
year : 마감년도
month : 마감월
day : 마감일
hour : 마감시각
estimated_time : 예상소요시간
importance : 중요도 (1~5)
done : 완료 유무 (0: 미완, 1: 완료)


//////////////////////////////////////////////////////
//////////////////////UI 설명////////////////////////
//////////////////////////////////////////////////////


1. 메인 화면
  ▷ 좌측 화면 (타임라인)
    ○ 요일 표시 on/off : 클릭 시 좌측 날짜에 요일 표시 on/off
    ○ 타임라인 단위 : 클릭 시 타임라인의 단위를 일별/시간별 전환
  ▷ 우측 화면 (과제정렬)
    ○ 정렬기준 (클릭하여 설정)
      - urgen : 긴급도(urgency)가 높은 순으로 정렬.         긴급도 = (예상소요시간/남은시간)*(1+0.001*중요도)
      - dday : 마감날짜 순으로 정렬
      - esti : 예상시간(estimated time) 순으로 정렬
    ○ 과제 블록
      - 긴급도 시각화 : 과제 블록의 색이 진할수록 긴급한 과제.         블록 좌측의 배터리 모양에 빨간색 영역 넓이가 넓을수록 긴급한 과제.
      - 예상 소요시간 간편 조작 : 예상 소요시간 옆의 상하 버튼을 이용하여               앞으로 남아있는 과제에 대한 예상 소요시간을 
               1시간 단위로 조작할 수 있음.
      - 과제 수정(edit) : 클릭시 해당 과제를 수정할 수 있는 창을 띄움.
              우측 상단 “new Work”를 눌렀을 때 나타나는 화면과 동일.
      - 과제 완료(done) : 과제 블록이 회색으로 변하며 
               예상 소요시간이 0으로 변하고 버튼의 문구가 “done!”으로 변함.
               좌측 타임라인 상의 블록도 회색으로 변함.
               다시 누르면 done 버튼을 누르기 전의 상태로 되돌아감.
      - 과제 삭제 : 클릭 시 과제를 데이터상에서 영구삭제.
  ▷ 새로운 과제 입력(new Work) : 클릭 시 새로운 과제를 입력하는 창을 띄움.

2. 과제 입력/수정 화면
  ▷ 과제 제목 입력 : 클릭 후 타이핑하여 과제 제목 입력(한글 가능)
  ▷ 날짜 입력 : 연/월/일/시를 클릭하여 상하 버튼을 이용해 조정 가능.
               달력을 클릭하여 연/월/일 조정 가능.
  ▷ 중요도 입력 : 중요도를 1~5까지 선택.
  ▷ 예상 소요시간 입력 : 1시간 단위로 과제 예상 소요시간 입력.
  ▷ back : 메인 화면으로 돌아감.
  ▷ save : 저장 후 메인화면으로 돌아감. 
           단, 제목이 없을 경우, 제목란이 클릭되며 이동되지 않음.

3. 그래프 화면
  ▷ x축 : 과제 마감날짜
  ▷ y축 : 해당 마감 날짜에 할당된 과제들의 예상 소요시간 합.
  ▷ 범주 지정 : 그래프로 표현할 과제의 범주를 4일/1주/2주/4주 단위로 조정.
